Forgotten Crypt is a little rpg-like software made with C and only C. Nothing else

## The idea

The game contains some limited (since this is meant to use only C with standard libraries) features, such as:

1. Five rooms all connected (the crypt, which is basically a small dungeon)
2. Turn-based combat with enemies
3. Three items that the player can hold on the inventory
4. Persistent session state. Enemies die and stay dead
5. Victory... or defeat, based on your outcome

And other features.

## Why?

Because I wanted to do something new. And I am also studying C and other languages such as C++ and Rust for hobby. And I also really love the fantasy vibe, so a game like this sounded like a nice way to learn, practice and also have fun!
